# Group Portfolio (Bootstrap)

A responsive group portfolio website built with **HTML**, **CSS**, and **Bootstrap 5** to showcase our team members' profiles, backgrounds, and shared interests.

## Features
* **Team Overview (`index.html`):** Main landing page introducing the group and project layout.
* **Member Profiles (`about.html`):** Detailed information about the group and individual members.
* **Interests Showcase (`interest.html`):** Highlights of our team's hobbies, skills, and personal interests.
* **Curriculum Vitae (`Vitae/`):** Dedicated section containing individual resumes/CVs of each member.

## Tech Stack
* **Frontend:** HTML5, CSS3, Bootstrap 5.3.8
* **Hosting:** GitHub Pages
