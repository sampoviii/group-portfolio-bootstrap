# Group Portfolio (Bootstrap)

A responsive group portfolio website built using HTML, CSS, and Bootstrap 5.3.8. This project showcases our team members' profiles, curriculum vitae, and shared interests.

## Pages
* **Home (`index.html`)** — Main landing page and team overview.
* **About (`about.html`)** — Information about the group and individual members.
* **Interests (`interest.html`)** — A showcase of our hobbies, skills, and interests.
* **Vitae (`Vitae/`)** — Individual resumes/CVs of the group members.

## Built With
* HTML5
* CSS3
* Bootstrap 5.3.8
